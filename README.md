# Fake Rate (Geode mod, GD 2.2081)

Adds a **Fake Rate** button to the level page (next to the normal comments / download-song buttons).
Set stars, difficulty (Auto -> Extreme Demon), Featured / Epic / Legendary / Mythic and verified coins.
Visual only: nothing is sent to the servers and only you can see it.

## Build
1. Install Geode CLI + SDK: https://docs.geode-sdk.org/getting-started/
2. `geode build`  (set GEODE_SDK first)
3. The `.geode` file lands in `build/` -> drop into your `geode/mods` folder.

Change `id` and `developer` in mod.json first.
